# 使用截图与来源说明

这组截图对应 0.1.0 预览版，共八张。网页界面、真实命令记录排版与诊断示例分别注明，便于对照操作和复核。文档与截图更新不改变已发布便携包的运行代码或 SHA-256。

| 顺序 | 画面 | 类型与范围 |
| --- | --- | --- |
| 1 | 发行页附件 | GitHub 实际公开页面，展示 ZIP 与校验文件；自动生成的源码附件不是运行包 |
| 2 | 下载校验与解压入口 | 真实匿名下载和 ZIP 文件记录的只读排版，不是文件管理器截图 |
| 3 | 中文菜单 | 真实交互菜单输出排版，不是原生终端截图；未启动或修改生产服务 |
| 4 | 挂载与保存入口 | 实际命令输出，独立临时配置，临时路径脱敏；示例域名没有建立公网连接 |
| 5 | 诊断示例 | 真实本机临时网关的诊断节选，上游未连接为预期结果；不能当作上游成功证据 |
| 6 | 配对页 | 软件实际网页，仅回环临时实例，不含可用码，不是手机外网实拍 |

## 截图的边界

- 本轮截图未重启生产网关、未改正式 Harness 配置、未停止正在进行的任务，也没有请求模型生成新内容。
- 为截图创建的临时配置、配对状态和网关在拍摄后清理；真实状态目录和配对资料没有公开。
- 截图使用网页内容区域，不含顶部电脑操作控制图标。没有对模型回复或错误提示进行补字、改字。
- Windows 原生 ACL／计划任务／Host、Linux 原生登录自启、真实手机工具批准与切网长任务恢复，仍按 README 的“尚待验证”范围处理。
- 八张公开图的字节数与 SHA-256 见 [截图清单](../screenshots/manifest.json)。

## 操作时遇到问题

请按主说明的顺序核对：官方 Host 本机可用 → 选择真实 profile → HTTPS 根路径入口 → 启动 → 上游认证诊断 → 最新一次性配对 → 简单消息回复。先完成简单消息收发，再尝试正式任务。

反馈可附脱敏后的诊断结果和错误画面；不要上传配对码、Cookie、私钥、真实会话或整个状态目录。
